# Competitive Advantage — Artone (2026-11-22)

方法: 競合調査（有料・無料を問わず）→ お金の流れの分解 → マスク思考法＋
ソクラテス問答を、意味のある知見が出るまで反復（2ラウンド実施）。
判定の出発点は作成者の原則: 個人データを持たない／提供はソフトウェアのみ
（運営費を負担しない）／本体は無料。

## 市場とお金の流れ

| 競合 | 形態 | 収益モデル |
|---|---|---|
| Adobe Premiere Pro | デスクトップ | サブスクのみ $22.99/月。無料枠なし |
| DaVinci Resolve | デスクトップ | 無料版＋Studio $295 買い切り。本体はハードウェア販売の入口 |
| Final Cut Pro | デスクトップ (Mac) | $299.99 買い切り。Apple 生態系の一部 |
| CapCut | モバイル/Web | 無料＋Pro $19.99/月、AI クレジット制。TikTok 導線 |
| VEED | ブラウザ（クラウド） | 無料は透かし入り。有料 $12/人/月〜、AI・字幕のメーター課金 |
| Kapwing | ブラウザ（クラウド） | 無料は透かし＋4分上限。Pro $16/人/月、ストレージ枠課金 |
| Descript | クラウド | $16/人/月〜、文字起こしのメーター課金 |
| Clipchamp | ブラウザ | 1080p 無料。Premium は Microsoft 365 の抱き合わせ |

金が溜まる先は4つ: (a) 道具の家賃（サブスク）、(b) 計算のメーター
（AI クレジット・字幕分数 = サーバー GPU 費用の転嫁）、(c) 素材の保管料と
人質（クラウドに素材とプロジェクトを置かせ、枠課金と乗り換えコストを立てる）、
(d) プラットフォームの入口商品（ハード・OS・投稿導線への誘導）。
全競合が「素材か、アカウントか、計算のどれかを自社側に置く」ことで
課金点を確保している。

## 反復の記録

### ラウンド1 — 「プロ級＝機能パリティ」を疑う

- 疑った前提: 価値は Resolve/Premiere との機能パリティにある。
- 消えたもの: パリティ競争そのもの（パリティ機能は Resolve が無料で配る
  以上、誰もお金を払わない）。「無料が優位」も Resolve 無料版と CapCut
  無料枠の前で消えた。
- 生き残ったもの: 素材が端末から一切出ないこと。OTIO/EDL/FCPXML による
  他ソフトとの往復（相互運用性）。

### ラウンド2 — 削除テストで分断線を見直す

- 「ブラウザで開ける手軽さ」を消しても、デスクトップ殻があるので製品は立つ。
- 競合側に「サーバーを持たない」を当てると前提が崩れた: VEED/Kapwing の
  「ブラウザエディタ」は、素材を自社クラウドへ上げるための細い入口に
  すぎない。ネットを切れば彼らは止まるが、Artone は何も変わらない。
- 意味のある知見: 市場の本当の分断線は「デスクトップ vs ブラウザ」ではなく
  「素材が誰かのサーバー負荷（＝人質）になるか、端末から出ないか」。
  課金点の4類型すべてが「自社側に置く」ことを前提にしており、置く場所を
  持たない設計とは両立しない。

## 構造的優位

Artone はサーバーを持たないため、利用者の素材を人質にも計算をメーターにも
できず、競合の全収益モデル（家賃・AIクレジット・ストレージ枠・
プラットフォーム誘導）が構造的に成立しない場所で、プロ級の編集を
無条件に無料で提供し続けられる。

補強する既存の実態:

- AI 推論はオンデバイス（Transformers.js）。AI クレジットという課金点が
  生まれる余地がない。
- OTIO/EDL/FCPXML の往復編集により、プロジェクトも人質にならない。
  乗り換えコストを収益の土台にする設計と正反対である。
- 作成者は利用者の素材・個人データを一切保持しない（大原則）。

   なっている。構造的優位を冒頭の1文に置く。
2. 版数の実態一致（バッジ 3.1.0 と package.json 3.0.0 の不一致是正）。
   本書と同梱で実施。
3. ブラウザ競合との対比表を README に置く（透かし・分数上限・アップロード
   の有無）。初見の利用者が10秒で違いを掴めるようにする。
4. OTIO 往復の実証を看板に変える（Resolve/Premiere との往復を実ファイルで
   検証し、その記録を README から辿れるようにする）。
